# ВЕНЕМАК

Демонстрационный стенд медицинского AI-ассистента для предварительного анализа медицинских изображений.

> **Важно.** Это proof-of-concept, а не медицинский продукт. Не загружайте персональные данные пациентов. Используйте только обезличенные изображения. Результат анализа не является медицинским заключением.

---

## Технологии

- **Next.js 15** — App Router, Server Components, Route Handlers
- **TypeScript** — строгая типизация, без `any`
- **Tailwind CSS v3** — без сторонних UI-библиотек
- **Google Gemini 2.0 Flash** — мультимодальный анализ изображений (бесплатный tier)

---

## Функциональность

- Загрузка медицинского изображения (JPG, PNG, WEBP, до 10 МБ)
- Предпросмотр изображения в браузере
- Подтверждение обезличенности изображения (чекбокс)
- Текстовый вопрос врача
- Структурированный ответ AI в формате ВЕНЕМАК
- Копирование ответа в буфер обмена
- Сохранение вопроса и последнего ответа в `localStorage`
- Опциональная защита доступа по токену (`?token=...`)
- Rate limit: 100 запросов в сутки на весь стенд (in-memory)

## Быстрый старт

### 1. Установить зависимости

```bash
npm install
```

### 2. Настроить переменные окружения

Скопировать файл примера:

```bash
cp .env.local.example .env.local
```

Открыть `.env.local` и заполнить:

```env
# Обязательный. Получить бесплатно на aistudio.google.com → Get API key
GEMINI_API_KEY=AIza...

# Опциональный. Если задан — доступ только по /?token=значение
DEMO_ACCESS_TOKEN=
```

### 3. Запустить в режиме разработки

```bash
npm run dev
```

Открыть [http://localhost:3000](http://localhost:3000)

### 4. Сборка для продакшена

```bash
npm run build
npm run start
```

---

## Переменные окружения

| Переменная | Обязательная | Описание |
|---|---|---|
| `GEMINI_API_KEY` | Да | API-ключ Google Gemini. Получить бесплатно на [aistudio.google.com](https://aistudio.google.com) |
| `DEMO_ACCESS_TOKEN` | Нет | Если задан, страница доступна только по `/?token=значение`. Если не задан — доступ открыт |

---

## Защита доступа

Если задан `DEMO_ACCESS_TOKEN`, открыть стенд можно только передав токен в URL:

```
http://localhost:3000/?token=ваш_токен
```

При отсутствии или неверном токене отображается экран «Доступ запрещён».

- Мобильное приложение
- Интеграция с МИС

---

## Безопасность и приватность

- Изображение передаётся напрямую в Google Gemini API и **нигде не сохраняется**: ни на сервере, ни в базе, ни в `localStorage`
- В `localStorage` хранятся только текст вопроса и текст последнего ответа
- Кнопка «Очистить» удаляет все данные из `localStorage`
- Файл обрабатывается в памяти один раз и не пишется на диск
